VTManager v1.0.2 使用须知
==========================

【这是什么】
一个轻量便捷的磁盘视图管理工具：为散落在硬盘里的影视与图片，
提供浏览、封面、播放、搜索、标签收藏、重命名与回收站等能力。
所有操作直接作用于你硬盘上的真实文件，纯本地运行、无需联网、不上传任何数据。

【怎么安装】
macOS（Apple Silicon / Intel）：
  1. 解压下载到的 zip（或打开 dmg）；
  2. 把 VTManager.app 拖进「应用程序」文件夹；
  3. 首次打开若被系统拦截：在访达中「右键 VTManager.app → 打开」，
     再点一次「打开」即可（应用为开发者自签名、未经 Apple 公证，
     这是 macOS 对未公证应用的标准提示，仅首次需要）。
Windows：
  暂无预编译安装包，可参考项目文档用源码自行构建。

【怎么用】
1. 双击启动，选择存放影视 / 图片的目录作为资料库根目录；
2. 首次扫描在后台进行，可边扫边浏览，之后每次打开自动增量同步；
3. 双击视频即播、双击图片即看；完整功能与快捷键见《操作手册.html》。

【建议第一件事】
打开「设置 → 资料库与索引 → 重新扫描全盘索引」，
这样全盘模糊搜索、最近添加与统计功能即可完整可用。

【数据说明】
应用只在资料库根目录创建一个 .VTManager 隐藏目录：
  - vtmanager.db   配置与索引（请勿删除）
  - covers/        手动设置的封面（请勿删除）
  - cache/         自动缩略图与预览缓存（可随时清空，自动重建）
                   设置面板中可直接查看并一键进入该目录
  - .trash/        回收站（删除的文件在此，可恢复，支持自动清除天数）

【系统要求】
macOS 11+（Apple Silicon / Intel）；无需安装任何运行环境，ffmpeg 已内置。
纯本地运行，除 TMDB 刮削（需自行填写 API Key）外不发起任何网络请求。
