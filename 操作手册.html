Performance

性能全面进化 v1.0.2 新增 9 项

从系统解码、缓存格式到编译优化——每一毫秒、每一兆字节都不放过。以下为本轮实测收益。

AVFoundation 视频主路径 秒级截帧NEW

视频元数据探测与截帧优先走 macOS 系统解码器（AVFoundation），失败才回退 ffmpeg——发布包因此移除 ffprobe，安装体积立减 49MB。

WebP 智能缓存 体积 −40%NEW

缩略图与预览缓存从 JPEG 迁移 WebP（有损编码，缩略图 80 / 预览 88），解码更快、内存更低，同样的空间装下更多封面。

目录列表内存缓存 翻目录零等待NEW

目录列表 3 秒内存缓存 + 上限 64 条，浏览与分栏切换不再重复全量枚举；所有写操作即时失效，数据永不过期。

弹窗组件代码分割 主包 −33%NEW

10 个低频弹窗改为按需异步加载，首屏主包从 104.75kB 降至 70.46kB，打开应用更快一步。

空闲预生成缩略图 即点即有NEW

浏览空闲时后台批量预生成当前目录缩略图（单批 400 张、扫描优先让位），打开目录不再等缩略图逐个加载。

数据库一键优化 VACUUM 压缩NEW

设置面板新增「优化数据库」：WAL 截断 + 索引优化 + VACUUM 压缩，一次点击即显示释放空间，索引更快更瘦。

Rust 激进编译 二进制更小NEW

全程序链接优化（fat LTO）+ panic=abort，移除无用栈展开代码路径，主程序体积再缩、运行更快。

增量索引扫描 最快 12×

对比文件快照 (path + 修改时间)，未变化的文件直接跳过，仅处理新增 / 修改 / 删除，重扫几乎瞬时完成。

大图预览降采样 内存 −90%

超过 1600px 的大图自动生成 WebP 预览（1.0.2-r4 起体积再减 60%），查看器与画中画共用缓存，打开不再爆内存。

缩略图线程自适应 按核数 1–8NEW

缩略图并行线程数按 CPU 核数自动适配（不再写死 4），多核机器首屏缩略图更快。

FAQ

常见问题

清除缓存 / 优化数据库会影响我的媒体文件吗？
完全不会。一键清除只删除缓存目录（缩略图 / 大图预览 / 转封装缓存）；优化数据库只压缩索引文件本身。你的原始视频、图片、标签、收藏与观看进度都保存在媒体原目录与索引数据库中，不受任何影响，重新浏览时会按需重建。
扫描到一半可以开始浏览吗？
可以。数据库开启 WAL 并发模式，扫描写入与浏览查询并行不互锁；缩略图线程按核数自适应并行生成，空闲预生成还会在扫描之后自动补全，首屏数据即刻可用。
目录里文件特别多，会很卡吗？
不会。超过 120 项的目录自动启用虚拟滚动，页面只渲染可视区域内的卡片，滚动性能与目录大小无关，160+ 项的目录也能 60fps 平滑滚动。
缓存会无限增长占满磁盘吗？
不会。三重保险：① 缩略图 / 预览缓存超过保留时长（默认 1 小时，可在设置选 1 / 6 / 24 小时或永不，也可自定义输入任意小时数 0–8760）未被再次查看即自动删除，之后访问按需重建；② 缓存总量达到 2GB 上限自动清理最旧缓存；③ 转封装副本关闭播放器即删。缩略图与预览已压缩为 WebP（预览体积较早期方案减少约 60%），也可随时在设置面板一键清除或优化数据库，空间占用一目了然。
回收站会自动清空吗？误删了怎么办？
回收站默认开启到期自动清除：文件 / 文件夹进入回收站后按设定天数（默认 3 天，可在设置 → 回收站改为 0–365 天，0=永不）自动彻底清除；每条记录都会显示剩余天数与到期日期。修改设置后，站内全部条目按当前时间重置到期时间并即时刷新显示（无需重进回收站）。删除确认弹窗会提示「文件将于 N 天后自动清除，请及时查验」——只要在到期前进入回收站恢复，文件就完好无损；到期后文件将被彻底删除、无法找回。
播放器怎么加载字幕？截图存在哪里？
字幕：播放视频时自动探测同目录同名的 .srt / .vtt（含「电影名.zh.srt」等多语言后缀写法）；若未自动加载，可在控制栏 CC 菜单「选择字幕文件…」手动指定，或点「关闭字幕」清除。C 键开关字幕，字号 0.8 / 1 / 1.2 / 1.5 可调，画中画全屏窗口同步显示。截图：按 S 键或点控制栏相机按钮，当前帧以原分辨率 PNG 保存——默认保存到资料库根目录的 captures/ 文件夹，可在 CC 菜单「截图保存目录…」改成任意位置（下次启动仍记住）。
切换资料库后，设置会变吗？
不会。所有应用设置（主题、回收站自动清除天数、缓存保留时长、播放 / 看图行为等）均为全局设置，存储在应用数据目录中，与资料库相互独立——切换资料库根目录不会重置任何设置；从旧版本升级时首次启动会自动把原资料库设置一次性迁移为全局默认，无需重新配置。
缓存目录在哪？长按右方向键是做什么的？
缓存目录：当前资料库的缓存位于资料库根目录的 <库根>/.VTManager/cache 下（thumbs 缩略图 / previews 大图预览 / scrubs 帧预览精灵图 / remux 转封装副本）。打开设置 → 存储空间，在「缓存保留时长」下方即可看到完整路径，点「进入缓存目录」按钮一键在 Finder / 资源管理器中打开；切换资料库后该路径自动跟随更新。长按加速：播放视频时按住右方向键不放约 0.4 秒即以当前倍速的 2 倍速播放（如 1.5× → 3×，上限 6×），松开立即恢复原倍速，适合快速跳过片段；轻点一下仍是「下一个视频」，不受影响。
